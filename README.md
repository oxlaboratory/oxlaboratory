## ⚡ OXIS

**OXIS is a programmable workspace for building, automating and managing software.**

One application brings together:

- 🧩 Lua extensibility
- ⚙️ Workflows & automation
- 📝 Document editing
- 💻 Integrated terminal
- 📁 Project management
- 🔌 Plugin ecosystem
- 🌐 Browser-rendered interface
- 🔗 GitHub & GitLab workflows
- 🛠️ Developer tooling
