## ⚡ OXIS — the terminal you can script

Your real **PowerShell, bash, zsh or fish**, plus a built-in editor, workspaces, workflows, full-colour output, deep theming and Lua plugins. One ~14&nbsp;MB binary for Windows and Linux. No account. No telemetry.

| | |
|---|---|
| 🐚 **Your shell, unchanged** | Your profile, aliases and tools in 24-bit colour, with vim, less, htop and other full-screen programs |
| 📝 **Built-in editor** | Open files beside the terminal with syntax highlighting, plus an image viewer for PNG, SVG, JPG and more |
| ⚙️ **Workflows & tasks** | Chain commands into repeatable workflows and run your project's scripts by name |
| 🧩 **Lua plugins** | Commands, keybinds and events, plus APIs for processes, file watching, streaming HTTP and the editor |
| 🛒 **Plugin Market** | Install community plugins in one command, or publish your own |
| 🎨 **Deep theming** | Every colour is a theme key, and themes switch live |
| 🗂️ **Workspaces** | OXIS detects your project and remembers its tabs, tasks and settings |
